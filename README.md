# Xbox 360 Backwards Compatibility Update (November 2007)

`Xbox360_BC_Update_Nov2007.iso` is Microsoft's final Xbox 360 backwards compatibility
update (`default.xex`, 27 Nov 2007) wrapped as an ISO 9660/Joliet image with the file at
the disc root.

## Burn (macOS)

```
./burn.sh            # waits for a blank disc, burns, verifies, ejects
```

A CD-R or DVD-R both work (it's 13 MB). Insert the disc into the Xbox 360 with a hard
drive attached and accept the update prompt.
